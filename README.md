# Portfolio — Facundo Luna

## 📑 Descripción

Portfolio personal como **Backend Developer (Java + Spring Boot)**. Reúne mis proyectos principales, las tecnologías con las que trabajo, mi CV descargable y un formulario de contacto.

Proyectos destacados:

- **InventoryIQ**: sistema de apoyo a decisiones de inventario con arquitectura hexagonal y DDD.
- **Banking System**: API bancaria con JWT, RBAC, 108 tests automatizados y CI/CD con GitHub Actions.
- **URL Shortener**: acortador de URLs con analíticas de clics, Spring Security y JWT.

---

## 💻 Correr en local

```bash
npm install
npm run dev
```

Para que funcione el formulario de contacto, crear un archivo `.env` con las credenciales de EmailJS:

```
VITE_EMAILJS_SERVICE_ID=...
VITE_EMAILJS_TEMPLATE_ID=...
VITE_EMAILJS_PUBLIC_KEY=...
```
